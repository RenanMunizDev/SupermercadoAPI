# SupermercadoAPI
API RESTful para gerenciar produtos e vendas de um supermercado, desenvolvida em .NET.

## Funcionalidades
- Listar produtos
- Adicionar novos produtos
- (Adicione mais conforme o projeto cresce)

## Como rodar
1. Clone o repositório: `git clone https://github.com/RenanMunizDev/SupermercadoAPI.git`
2. Restaure dependências: `dotnet restore`
3. Rode a API: `dotnet run`
